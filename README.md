# EcoAgent22

## EcoAgent for ECOTRACK Delivery

EcoAgent22 is an Android application project designed to support delivery workflows for ECOTRACK.

### Project

- Platform: Android
- Language: Java
- Project name: EcoAgent22
- Repository: EcoAgent22

### Main Components

The project includes Android application components and an accessibility service designed to support automated interaction with supported Android interfaces.

### Development

This repository contains the source/project files and build resources for EcoAgent22.

To build the application, open the project with Android Studio and allow Gradle to synchronize the project.
